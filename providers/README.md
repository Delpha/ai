# Provider plugins

This directory contains the Delpha plugins for AI clients. Each bundles the
[skills](../skills/) and the MCP connection to `https://mcp.delpha.ai/mcp`.

| Client | Plugin | Manifest | Connection | Marketplace |
| --- | --- | --- | --- | --- |
| Claude Code | [claude/plugin](claude/plugin/) | [plugin.json](claude/plugin/.claude-plugin/plugin.json) | [.mcp.json](claude/plugin/.mcp.json) | [.claude-plugin](../.claude-plugin/marketplace.json) |
| Codex | [codex/plugin](codex/plugin/) | [plugin.json](codex/plugin/.codex-plugin/plugin.json) | [.mcp.json](codex/plugin/.mcp.json) | [.agents/plugins](../.agents/plugins/marketplace.json) |
| Cursor | [cursor/plugin](cursor/plugin/) | [plugin.json](cursor/plugin/.cursor-plugin/plugin.json) | [mcp.json](cursor/plugin/mcp.json) | [.cursor-plugin](../.cursor-plugin/marketplace.json) |

The Claude Code plugin also ships two [commands](claude/plugin/commands/). Install a plugin with the
[commands in the README](../README.md#get-started). Plugins contain no credentials; you finish
Delpha sign-in in your client. Each plugin has its own version.

## Layout

Each client gets its own `providers/<client>/plugin/` directory, so its manifest, connection,
skills and other assets stay isolated as more clients are added.

## Skills

**Do not edit skill files in provider directories.**

`providers/*/plugin/skills/` are copies of the canonical [skills/](../skills/), generated by
`python3 scripts/sync_skills.py`. CI fails when a copy differs from the source.
