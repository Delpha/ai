# Security policy

Report vulnerabilities privately to **support.api@delpha.io** with the affected component
and reproduction steps. Do not include live credentials or unnecessary personal data,
and do not open a public vulnerability issue.

The repository distributes skills, examples and MCP configuration without credentials.
Use Delpha OAuth sign-in or a key stored in your protected environment.
Keep keys out of source control, browser code, logs and screenshots.
Give each integration its own scope, expiry and Credit ceiling.
Revoke exposed keys at [Developer → API keys](https://app.delpha.ai/developer/api-keys).

See [credential and data handling](skills/delpha/references/security.md) and
[Delpha privacy guidance](https://help.delpha.io/delpha-api-and-mcp/api/data-sources-and-privacy).
